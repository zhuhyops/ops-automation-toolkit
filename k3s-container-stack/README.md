# 容器化与轻量级云原生架构实践

## 项目背景
为了解决“环境不一致”导致的部署失败问题，本项目提供了基于 Docker 与 K3s 的标准化编排清单。通过定义资源限制（Resources Quotas）与健康检查（Liveness Probes），保障业务在容器化环境下的稳定性。

## 核心交付内容
1. **K3s 生产级编排：** 提供副本数为 3 的高可用部署模板，配置了 CPU/Memory 的软硬件限制，防止 OOM (内存溢出) 导致宿主机崩溃。
2. **多服务联动架构：** 通过 `docker-compose` 实现数据库持久化卷挂载与 Redis 缓存层集成，支持一键拉起完整的测试/开发沙箱。
3. **健康检查机制：** 引入 `LivenessProbe` 探针，实现业务故障后的秒级自动愈合。

## 适用场景
* 快速搭建与生产环境对标的自动化测试沙箱。
* 中小企业轻量级 K8s 集群（K3s）的业务上线模板。
