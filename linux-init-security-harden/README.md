# Linux 服务器初始化与安全加固脚本

## 项目背景
针对新交付的 Linux 服务器，手动进行基础配置和安全加固效率低且易遗漏。本项目通过自动化脚本实现环境的 **“标准化交付”**，旨在收敛攻击面并提升系统在高并发场景下的稳定性。

## 核心功能
* **DevSecOps 安全：** 禁用 SSH DNS 反解加速登录，强制禁用空密码，关闭 IPv6 减少暴露面。
* **网络性能优化：** 针对内核参数进行调优，开启 `tcp_tw_reuse` 解决高并发下的连接堆积，启用 `tcp_syncookies` 防御 SYN 洪水攻击。
* **运维规范化：** 统一时区与 NTP 时间同步，确保分布式环境下日志时间戳的一致性。
