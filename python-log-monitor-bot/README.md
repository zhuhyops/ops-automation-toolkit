# 异常日志智能清洗与监控告警机器人

## 架构痛点与项目背景
在传统安全运营中，Web 日志（如 Nginx/Apache）的人工巡检存在极大的滞后性。当遭遇恶意目录扫描、SSH 暴力破解或 SQL 注入探测时，运维人员往往在事后才能察觉。
本项目通过 Python 编写轻量级监控脚本，结合企业级 IM（钉钉/飞书）的 Webhook 接口，实现了**“异常流量秒级预警”**，有效填补了中小企业在重型 WAF 部署前的安全监控盲区。

## 核心技术实现
1. **正则高优提取 (`re` 模块)：** 使用预编译的正则表达式 (`re.compile`) 高效剥离日志中的访问源 IP 与 URL 请求体，降低 CPU 消耗。
2. **简易威胁情报库：** 内置轻量级 Payload 规则，精准匹配 `union select` (SQLi)、`<script>` (XSS) 等 OWASP Top 10 高危特征。
3. **高频聚合判定 (`collections.Counter`)：** 利用 Counter 类实现高效的时间复杂度统计，迅速定位 CC 攻击与高频扫描的源头 IP。
4. **自动化告警流 (`requests`)：** 将异常数据结构化为 Markdown 消息卡片，通过 HTTP POST 实时推送至运维应急响应群。

## 实战价值
该脚本支持挂载于 Linux `Crontab` 定时任务中运行。在实际环境中，已预留联动扩展位，可将抓取到的高频恶意 IP 直接对接系统级的 `iptables` 规则库或阿里云安全组 API，实现 **“发现即封堵”** 的全自动化安全闭环。
